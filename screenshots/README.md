# Screenshots

Save your screenshots from running `toolkit.py` in this folder.

Required evidence:
- Main menu handling an invalid choice.
- Calculator in action.
- To-do list in action (show a task being added or displayed).
- Number guessing game in action.
- Optional: the friendly quit message.

Suggested filenames: `invalid-menu.png`, `calculator.png`, `todo-list.png`, `guessing-game.png`, and `quit.png`.

These screenshots must be captured from your own program run; this README is only a reminder and is not a substitute for the screenshots.
